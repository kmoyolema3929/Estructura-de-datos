# Estructura-de-datos

Repositorio académico que contiene los trabajos, actividades prácticas, tareas, ejercicios de clase y proyecto final desarrollados durante el segundo parcial de la asignatura **Estructura de Datos**.

## Objetivo del repositorio

Centralizar y mantener organizados todos los trabajos realizados durante el segundo parcial de la materia de Estructura de Datos, facilitando el seguimiento del progreso académico y el control de versiones de cada actividad.
